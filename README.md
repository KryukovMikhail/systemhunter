# System Hunter

Тренажёр собеседований на системного аналитика уровней Junior, Junior+, Middle, Middle+ и Senior.

**Сайт:** https://kryukovmikhail.github.io/systemhunter/

## Разделы

- **Тренажёр интервью** — 32 вопроса с эталонными ответами, таймером и самооценкой по ключевым пунктам.
- **Обучение** — 7 уроков: требования, BPMN и UML, API, БД и SQL, интеграции, архитектура, процессы и коммуникации.
- **Тесты** — тесты по темам и сводный экзамен.
- **Карта компетенций** — матрица из 10 навыков по 5 грейдам, радар-диаграмма и список пробелов до целевого грейда.

Сайт состоит из одного файла `index.html` без сборки и зависимостей. Прогресс хранится в localStorage браузера.
