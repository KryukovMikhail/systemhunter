# Технический стек и устройство

System Hunter — статический сайт без сервера и сборки: одна HTML-страница с встроенными стилями, скриптом и всем учебным контентом. Публикуется через GitHub Pages.

## Коротко

| Слой | Что используется |
|---|---|
| Разметка и логика | HTML5 + чистый JavaScript (ES2020+), без фреймворков и библиотек |
| Стили | CSS3 (custom properties, grid/flex, `color-mix`, `:has()`, `@media`), встроены в `index.html` |
| Темы | Светлая и тёмная, переключаются автоматически по `prefers-color-scheme` |
| Графика | Встроенный SVG: логотип-прицел, радар-диаграмма компетенций и столбчатая диаграмма баллов (генерируются кодом); фоновая сетка — CSS-градиенты |
| Шрифты | Google Fonts: Unbounded (заголовки), Golos Text (текст), JetBrains Mono (код, метки) |
| Хранение данных | `localStorage` браузера (целевой грейд, история интервью и тестов, уроки, самооценка, прочитанные книги) |
| Навигация | Hash-роутинг: `#home`, `#trainer`, `#learn`, `#tests`, `#results`, `#map`, `#lit` |
| Хостинг | GitHub Pages из ветки `main`, корень репозитория |
| Сборка, бэкенд, база данных | Нет |

## Устройство `index.html`

Внутри один блок `<style>` и один `<script>`. Скрипт делится на части, отмеченные комментариями `/* ============ … ============ */`.

1. **Данные (DATA)** — контент в виде JS-объектов:
   - `LEVELS` — грейды: `j` Junior, `jp` Junior+, `m` Middle, `mp` Middle+, `s` Senior (название, опыт в годах);
   - `TOPICS` — темы: `req` требования, `model` BPMN и UML, `api` API и протоколы, `db` БД и SQL, `integ` интеграции, `arch` архитектура, `soft` процессы и коммуникации, `ai` ИИ в аналитике (AI PDLC, SDD);
   - `QUESTIONS` — вопросы интервью. Поля: `l` грейд, `t` тема, `q` вопрос, `a` эталонный ответ (HTML), `p` ключевые пункты для самооценки, `f` дополнительный вопрос интервьюера (необязательно);
   - `LESSONS` — уроки по темам: `title`, `min` (время чтения), `body` (HTML), `take` (что запомнить);
   - `TESTS` — тесты по темам. Вопрос: `q`, варианты `o`, индекс правильного `c`, пояснение `e`;
   - `COMPS` — компетенции для карты: `name`, `short` (подпись на радаре), `t` (тема для ссылки на урок), `lv` (ожидания для каждого из 5 грейдов);
   - `BOOKS` — книги: автор `a`, название `t`, тема `tp`, рекомендуемый грейд `l`, описание `d`;
   - `RESOURCES` — онлайн-источники: название `t`, ссылка `u`, тема `tp`, описание `d`.
2. **Состояние (STATE)** — объект `S`, загрузка и сохранение в `localStorage` с `try/catch`, утилиты `shuffle()`, `pct()`, управление таймером.
3. **Роутер (ROUTER)** — `go(route, opts)` выбирает функцию-экран из `VIEWS`, обновляет hash через `history.replaceState`, подсвечивает вкладку. Клики по элементам с `data-go` перехватываются одним делегированным обработчиком. Экраны перерисовываются через `innerHTML`.
4. **Экраны:**
   - `viewHome()` — главная: выбор целевого грейда, разделы, сводка прогресса (`stats()`);
   - `viewTrainer()` → `askQuestion()` → `finishInterview()` — тренажёр интервью;
   - `viewLearn()` — уроки с оглавлением и отметкой «изучен»;
   - `viewTests()` → `startTest()` → `askTest()` → `endTest()` — тесты и экзамен;
   - `viewResults()` + `trendChart()` — результаты: сводка, динамика интервью, таблица тем, слабые и сильные темы, история, сброс прогресса;
   - `viewMap()` + `radar()` — матрица компетенций, радар и список пробелов;
   - `viewLit()` — литература по уровням с фильтром по теме и отметками «прочитал».

### Логика тренажёра

- Подборка вопросов (`pool()`): выбранный грейд и тема. По умолчанию добавляются вопросы младших грейдов, как на реальном собеседовании.
- Из подборки берётся 5, 8 или 12 вопросов. Вопросы выбранного грейда идут в выборку в первую очередь, затем порядок перемешивается.
- На каждый вопрос идёт таймер; после 3 минут он становится красным.
- Балл за вопрос = отмеченные ключевые пункты / все пункты. Итог — среднее по вопросам.
- Вердикт: ≥80% — грейд подтверждён, ≥60% — почти готов, ниже — рано. Темы ниже 80% выводятся со ссылками на уроки.

### Логика тестов

- Вопросы и варианты ответов перемешиваются при каждом прохождении.
- Экзамен — 15 случайных вопросов из всех тестов.
- Сохраняется лучший результат; ≥80% считается «сдано».

### Результаты

- Столбчатая диаграмма в SVG: последние 12 интервью, цвет столбца по баллу (≥80% зелёный, ≥60% жёлтый, ниже красный), пунктир — порог 80%.
- Балл темы = среднее из среднего балла по теме в интервью и лучшего результата теста по теме (что есть). Темы ниже 80% попадают в «Слабые» со ссылками на урок и тест.
- Баллы по темам сохраняются у интервью начиная с этой версии; старые записи участвуют только в общей динамике.
- «Сбросить весь прогресс» — двойное нажатие, целевой грейд сохраняется.

### Карта компетенций

- Самооценка по каждой компетенции — число 0–5 (0 — не оценено, 1–5 — достигнутый грейд). Клик по ячейке ставит уровень, повторный клик снимает его.
- Радар строится в SVG: по оси на компетенцию (сейчас 11), 5 колец, зелёный многоугольник — текущий уровень, оранжевый пунктир — целевой грейд.
- Готовность к грейду = Σ min(уровень, цель) / (цель × число компетенций).

### Объём контента

- 5 грейдов, 8 тем;
- 38 вопросов интервью (Junior 8, Junior+ 7, Middle 8, Middle+ 8, Senior 7), у 7 есть дополнительный вопрос;
- 8 уроков;
- 8 тестов по 5 вопросов + экзамен;
- 11 компетенций × 5 грейдов = 55 описаний ожиданий;
- 20 книг и 15 онлайн-источников.

## Данные пользователя

Все данные хранятся только в браузере, на сервер ничего не уходит.

| Ключ `localStorage` | Что хранит |
|---|---|
| `systemhunter.v1` | `target` — целевой грейд; `interviews` — история интервью (грейд, балл, число вопросов, дата, минуты, баллы по темам `topics`); `tests` — лучший результат по каждому тесту и экзамену; `testLog` — история попыток тестов (до 200); `lessons` — изученные уроки; `self` — самооценка по компетенциям; `books` — прочитанные книги |

Если `localStorage` недоступен (приватный режим, запрет cookies), сайт работает, но прогресс не сохраняется между визитами.

## Оформление

- Цвета заданы токенами в `:root` (`--bg`, `--surface`, `--ink`, `--accent`, `--ok`, `--bad` и др.) и переопределяются для тёмной темы. Можно принудительно задать тему атрибутом `data-theme="dark"` или `"light"` на `<html>`.
- Адаптивность: брейкпоинты 900 px (одна колонка) и 520 px (телефон). Матрица компетенций на узком экране прокручивается горизонтально в своём контейнере.
- Учтены `prefers-reduced-motion`, видимый фокус для клавиатуры, отступы под вырезы экрана (`env(safe-area-inset-*)`).

## Как добавить контент

- **Вопрос интервью** — объект в `QUESTIONS` с полями `l`, `t`, `q`, `a`, `p` (и при желании `f`).
- **Урок** — ключ темы в `LESSONS`. Новая тема добавляется также в `TOPICS`.
- **Вопрос теста** — объект в массиве нужной темы в `TESTS`; правильный вариант указывается индексом `c`.
- **Книга** — объект в `BOOKS`; на странице книги группируются по грейду `l` автоматически. **Источник** — объект в `RESOURCES`.
- **Компетенция** — объект в `COMPS` с ровно пятью описаниями в `lv`. Радар подстраивается под число компетенций автоматически.

Если меняется структура сохранения `S`, стоит поднять версию ключа (`systemhunter.v2`), чтобы старые данные не ломали новую логику.

## Выпуск и проверка

- Выпуск — коммит в `main`. GitHub Pages публикует сайт автоматически за 1–2 минуты.
- Автотестов нет. Перед выпуском синтаксис скрипта проверяется через `node --check` на скрипте, вынутом из `index.html`.

## Поддержка браузеров

Современные Chrome, Edge, Firefox, Safari (iOS 15.4+). Используются `color-mix()` и `:has()`; в старых браузерах сайт работает, но без полупрозрачного фона шапки и подсветки отмеченных пунктов самооценки.
